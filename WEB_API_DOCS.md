# Веб-страница документации REST API

Добавлена интерактивная страница документации REST API в веб-интерфейс проекта.

## Расположение

**URL:** `http://your-domain.com/#/api-docs`

**Компонент:** `web/src/components/ApiDocs.tsx`

## Возможности

### 1. Справочник endpoints

- Интерактивная навигация по всем 9 endpoints
- Полное описание параметров запроса и ответа
- Цветовая маркировка по уровням (Tier 1/2/RAG)

### 2. Примеры кода

Для каждого endpoint доступны примеры на 4 языках:
- **curl** — для быстрой проверки в терминале
- **TypeScript** — для Node.js/Deno/браузера
- **Python** — с использованием requests
- **JavaScript** — fetch API для браузера

### 3. Интерактивность

- Переключение между примерами одним кликом
- Копирование кода в буфер обмена
- Адаптивный дизайн для мобильных устройств

### 4. Контекстная интеграция

- Автоматическая подстановка публичного URL сервера
- Для авторизованных пользователей — ссылка на получение токена в кабинете
- Единый стиль с остальным интерфейсом A2chatski

## Навигация

Страница доступна из нескольких мест:

1. **Главное меню** (Nav) — кнопка "API" в шапке сайта
2. **Кабинет** — ссылка "Документация API →" в футере
3. **Прямая ссылка** — `/#/api-docs`

## Данные

Все endpoints и их описания хранятся в константе `ENDPOINTS` внутри компонента:

```typescript
const ENDPOINTS: EndpointInfo[] = [
  {
    id: "list_case_categories",
    name: "Список категорий дел",
    method: "GET",
    path: "/rest/list_case_categories",
    tier: "–",
    description: "...",
    response: "...",
  },
  // ... остальные 8 endpoints
];
```

## Генерация примеров

Функция `generateCodeExample()` динамически генерирует примеры кода для каждого сочетания:
- endpoint × language × baseUrl × token

Поддерживаются placeholders для параметров: `<court>`, `<date>`, `<query>` и т.д.

## Цветовая схема

| Tier | Цвет | Описание |
|------|------|----------|
| Tier 1 | Зелёный (emerald) | Быстрый HTTP без капчи |
| Tier 2 | Жёлтый (yellow) | Браузер + автоматическая капча |
| RAG | Фиолетовый (purple) | Локальный поисковый корпус |

## Обновление документации

### Добавление нового endpoint

1. Добавьте запись в массив `ENDPOINTS`:

```typescript
{
  id: "new_endpoint",
  name: "Название нового endpoint",
  method: "POST",
  path: "/rest/new_endpoint",
  tier: "1", // или "2", "RAG", "–"
  description: "Описание endpoint",
  request: {
    param1: { type: "string", required: true, description: "..." },
  },
  response: `{ "example": "response" }`,
}
```

2. Примеры кода сгенерируются автоматически.

### Изменение базового URL

Базовый URL берётся из переменной `baseUrl` в компоненте. По умолчанию `http://localhost:8080`.

Для продакшена — обновите значение или получайте его из API:

```typescript
const baseUrl = window.location.origin; // использовать текущий домен
```

## Быстрый старт для пользователей

1. Откройте `http://your-domain.com/#/api-docs`
2. Выберите endpoint из списка слева
3. Получите токен в кабинете (`/#/cabinet`)
4. Скопируйте пример кода на нужном языке
5. Замените `<параметры>` и `YOUR_TOKEN` своими значениями
6. Выполните запрос!
